# 2026-11-16-01 Milestone A：Claude adapter 跑通

> 过程记录。稳定结论合并进 [09 协议](../09-agent-protocol.md) / [10 开发环境](../10-dev-setup.md)。

## 做了什么

- `spike/src/claude-adapter.mjs`：Claude Code `stream-json` adapter。
  - 一个 room/thread 一个长活 CLI 进程；`--bare --disable-slash-commands --strict-mcp-config --system-prompt-file`。
  - 解析 `system/init`（session_id）、`assistant`（text/tool_use）、`user`（tool_result）、`result`（usage/cost）。
  - `interrupt` = kill + 下次 `--resume`；`resume` 保持 session。
- `spike/src/claude-demo.mjs`：三阶段 demo（首轮 / 同进程连续 / kill+resume），写 JSONL 审计到 `spike/.tmp/audit.jsonl`。
- `spike/test/adapter.test.mjs`：`parseReply` / `buildAgentPrompt` 两个单测；总测试 14 个全过。

## 实测结果

- **Phase 1**：human @claude-dev → Claude 回复并 @reviewer → reviewer 回复。
- **Phase 2（同进程连续）**：Claude 记得上一轮方案；in=281 out=62 cost=$0.021245。
- **Phase 3（kill + `--resume`）**：同一 session id `86aecfe0-8ece-43a0-ad37-8b30d20c2b08`；Claude 记得刚才的登录方案；in=426 out=85 cost=$0.005023。
- **总计**：in=1843 out=319 **cost=$0.043918**；线程最终 `quiescent`。
- **精简参数效果**：一句“收到”从完整环境的 **24,702 tokens / $0.132** 降到 **942 tokens / $0.0048**。

## 问题与处理

- Phase 2 第一次跑报错：把 `post2.granted` 整个对象传给了 `runClaudeTurn`，应该传 `.envelope`；已修。
- CLI stderr 有 `[claude-code:unrecognized_model]` 警告；不影响运行。
- `capabilities.streaming=false`：v0 先收集完整 turn 再 yield 事件；真正的流式输出后续加。
- 冷启动/首轮仍会加载少量系统提示；warm 进程复用后成本明显降低（phase 2/3 输入 281/426 tokens）。

## 网络调研（回应“没有公网 IP”）

已写 [11 本地部署与无公网 IP 组网](../11-local-networking.md)：

- 自己的多台设备互访：**EasyTier**（14.7K★，国内、Windows、P2P/NAT 穿透、公共中继）最贴合；Tailscale/ZeroTier 备选。
- 要对公网开放：Cloudflare Tunnel（需域名/账号，国内质量待测）或小 VPS + frp/Matrix；frp 单装没用，必须有公网 `frps`。
- 结论：本地阶段 mesh VPN 够用；长期公开用 VPS 最稳。
