## 背景

上一版 `spike/ui` 是协议调试台：两个固定房间、没有创建流程、默认 `mention_or_reply`。用户试用后指出：

- 私聊和群聊分成两块，不像 QQ/微信/飞书；
- 不能创建 agent、私聊、群聊；
- 想私聊 dev，回的是 script-peer（只有一个写死的 DM）；
- 不 @ 没人回；@ dev 两个 agent 都回（agent→agent 链 + 脚本 mock）。

结论：协议层是真的，产品层是 demo。这一轮补产品层。

## 做了什么

### 新目录

- `app/`
  - `store.mjs`：`data/state.json`；首次从 `spike/.tmp` 导入 human/agents/rooms；默认系统提示。
  - `matrix-admin.mjs`：注册/登录/建房/邀请/join/members。
  - `gateway-host.mjs`：Engine + Gateway + clients + runtimes；动态 `attachAgent` / `attachRoom`。
  - `server.mjs`：控制面 API、房间摘要/未读、静态托管 `web/dist`。
  - `README.md`：运行、数据、API、排障。
- `web/`
  - React 19 + Vite 8；`App.jsx` + Sidebar / ChatView / AgentsView / NewChatModal / Avatar / Icon。
  - 单列会话（DM/群混排）、搜索结果、未读、聊天气泡、@ 自动补全、Agents 页、深链、深浅色、移动端。
  - `README.md`：开发/构建/约定。
- `agent-im/CLAUDE.md`：给后续 agent 的布局、命令、不变量、坑、改哪里。

### 协议/引擎增量

- `wakePolicy` 新增 **`human_all`**：人类消息唤醒所有 agent；agent 消息只唤醒被 @/回复/task owner 的。
- `maxAgentChain=3`：一条人类消息后最多连续 3 条 agent 消息；人类消息重置。
- `Gateway.addAgent()` / `Gateway.addRoom()`：运行时动态接入新 agent/房间。
- 测试从 25 → **27**（human_all、链上限）。

### 产品行为

- 新建 agent：注册 Matrix 用户 → 写 store → attach gateway → 自动开 DM。
- 新建私聊：按 agent 幂等建 `is_direct` 房间；不再共用一个 DM。
- 新建群聊：起名 + 多选 agent；逐个 join；引擎动态建 room/thread。
- 群聊不 @：所有 Claude agent 都会收到并自己判断；没有补充就 PASS。
- 侧栏统一显示 DM 和群，带最后一条、时间、未读。

## 验证

- `spike`: `node --test` → **27 pass**。
- 真实 Tuwunel + 真实 Claude：
  1. 新建 `@researcher`（Claude）→ 自动 DM → 发消息 → Claude 回复。
  2. 新建群「讨论组」（claude-dev + researcher）→ 不 @ 发一条 → **两个 agent 都回复**，内容各自符合角色。
  3. 新建 DM「Claude Dev」→ 不 @ 发消息 → Claude 回复。
  4. 侧栏/未读/Agents 页/hash 深链/深浅色截图核对。
- 成本：4 个真实 turn 约 **$0.14593**（`app/data/audit.jsonl`）。

## 过程中踩的坑

- **curl 中文**：Windows 控制台把 UTF-8 中文按 GBK 发出去，Matrix 里出现乱码；浏览器/Node fetch 正常。测试改用 Node。
- **DM 只有一个**：旧 `setup-matrix` 写死 `script === "reviewer"` 的 agent；现在按 agent 建 DM，旧 DM 保留为 script-peer。
- **两个 gateway 会重复回复**：同一个 agent token 只能一个 sync 客户端；启动 app 前停掉 spike gateway。
- **群类型不能按成员数推导**：单 agent 群只有 2 人，会被误判成 DM；现在 kind 以 store 为准，reconcile 只更新成员。
- **agent 说"能跑 PowerShell"**：`--bare` 仍带工具；默认提示已加"默认只对话，除非明确要求才用工具"。
- **中文 prompt 的旧消息**：Prompt 更新不会改历史消息；旧 DM 里的旧回复保留。

## 遗留

- 成本控制是下一步第一优先（triage/冷却/预算）。
- 没有删除/暂停/改名 agent、退群、邀请第二个人类。
- 没有流式、审批、附件、E2E 加密。
- 未读按最近 50 条算；轮询不是 push。
- agent 的 workspace 是空目录；要改代码需要 worktree/仓库挂载。
