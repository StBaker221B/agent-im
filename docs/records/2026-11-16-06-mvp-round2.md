# 2026-11-16-06 MVP 第二轮：身份一致性、邀请、删除、附件

- 记录时间：2026-11-16 下午。
- 状态：根据试用反馈修复/补功能。
- 关联：[13 MVP 架构](../13-mvp-architecture.md) · [09 协议 §14](../09-agent-protocol.md) · [05 MVP](2026-11-16-05-mvp.md)

## 用户反馈

- 群聊和私聊里的 Claude Dev 应该像同一个"人"：在一个会话里说过的内容，在另一个会话里也应该知道。
- 房间里不能邀请新成员。
- "+" 的新建入口把"新建会话"和"新建成员"混在一起，交互不清晰。
- 不能删除会话。
- 不能发文件/图片。

## 改动

### 1. 同一个 agent，跨房间记忆

- `ClaudeAdapter` 新增 `sessionScope: "agent" | "room"`；MVP 默认 `"agent"`。
- 一个 agent 只有一个 Claude session/CLI 进程，所有房间的 turn 共享同一份 transcript。
- 默认系统提示补充：
  - 跨房间共享记忆，不要每个房间当成陌生人；
  - 私聊原文/敏感内容不主动带到群聊，引用时概括，不确定先问。
- 代价：transcript 跨房间增长，token 成本更高；隐私是提示级约束，不是硬隔离。

### 2. 邀请成员

- `POST /api/rooms/:id/members {agentIds}`：invite + join，更新 store，`gateway.syncRoom` 把新成员写进 Engine room/thread。
- 群聊头部「邀请」按钮 + `InviteModal`；DM 不允许加人。
- 邀请不会重放历史给 agent 的 prompt；但 agent 加入后能看到 room 历史（Claude session 的当前 room 上下文）。

### 3. 新建入口拆分

- Sidebar `+` → `NewChatModal`，只有「私聊 / 群聊」。
- Agents 页「新建 agent」→ 独立的 `NewAgentModal`。
- `NewChatModal` 里没有 agent 时的空状态可以跳到新建 agent。
- 这样"新建会话"和"新建成员"不再共用一个语义模糊的弹窗。

### 4. 删除会话

- `DELETE /api/rooms/:id`：human + 所有 agent leave；`gateway.removeRoom` 删 engine room/thread；store 移除。
- 聊天头部垃圾桶按钮 + confirm。
- 注意：Matrix 服务器上的历史仍保留；这是"从我的列表删除"，不是管理员级销毁房间。

### 5. 图片/文件

- `POST /api/rooms/:id/upload {filename, contentType, data(base64)}`，≤8MB。
- 服务端上传 `/_matrix/media/v3/upload` → `mxc://`；图片发 `m.image`，其他发 `m.file`。
- `GET /api/media?uri=mxc://...`：服务端用 human token 走认证的 `/_matrix/client/v1/media/download/...` 流式返回（老的 v3 download 在 Tuwunel 上是 403）。
- UI：回形针按钮、FileReader 读 base64、图片内联、文件卡片下载；侧栏预览显示 `[图片]`/`[文件]`。
- agent 的 prompt 里把媒体标成 `[图片] filename` / `[文件] filename`，因为它拿不到附件内容。

- **跨房间记忆 PASS**：
  - 私聊说暗号 `蓝鲸-42` → 新建群问：它记得，但按隐私规则拒绝在群里复述（"需要的话回私聊确认"）。
  - 群里说发布代号 `海豚-7` → 私聊问：直接答出 `海豚-7`，并说明是在另一个 room 里得到的。
- **邀请 PASS**：`POST /members` 把 researcher 加进测试群，成员表变成 kudo/claude-dev/researcher。
- **图片 PASS**：SVG 上传 → `m.image` → `/api/media` 200 `image/svg+xml` 346 bytes。
- **删除 PASS**：测试群删除后 `bootstrap` 不再出现。
- `agent-im` 根目录 `npm run check` 通过；`spike` 27 tests 通过；`web` build 通过。

成本：本轮 4 个真实 Claude turn 约 **$0.112**；整个 MVP 验证累计 15 turn 约 **$0.340**（`app/data/audit.jsonl`）。

## 遗留

- 不能移除成员/改角色、不能暂停/删除 agent。
- 跨房间隐私仍是提示级；更严格需要 memory 摘要 + 每房间 session 或工具级隔离。
- 附件没有缩略图、断点续传、粘贴上传；8MB 限制是服务端内存读取的取舍。
- 删除会话只做 leave，不做 Matrix 管理员级销毁。
- 流式输出、工具审批仍未做。
