## 用户反馈

- 会话列表没有删除按钮/右键菜单。
- 点击头像看不到资料。

## 改动

### 1. agent 真正看到图片

- Gateway 在收到 `m.image`/`m.file` 时，用收到事件的 agent client 下载 mxc 到 `app/data/media/<mediaId>.<ext>`（`mediaDir` + `#cacheMedia`）。
- 给 agent 的文本变成 `[图片] 文件名\n本地文件: D:/.../media/<id>.svg`。
- 默认系统提示：**收到图片/文件必须先 Read 打开再回答，不要说看不到**。
- 验证：上传含 `VISION-OK 42` 的 SVG，Claude 一次回复就描述出文字和尺寸。

### 2. researcher 不回话

- 诊断：不是坏了。它在群里经常判断"别人已经答完，没有补充"就 PASS；DM 里其实会回。
- 默认提示新增：**私聊或人类直接提问/点名时必须回应，不要用 PASS 回避直接问题**。
- `@` 解析支持 displayName + Unicode：`@研究员` 能解析成 `@researcher`（server、gateway、UI 高亮/补全都改了）。
- 验证：单 agent 群发 `@研究员 请用一句话说明你的职责`；mentions 正确，researcher 正常回答。

### 3. 会话列表删除

- 每个会话 hover 出现 `⋯`，右键也有菜单；菜单里「删除会话」。
- 复用 `DELETE /api/rooms/:id`：所有本地成员 leave，store/engine 移除。

### 4. 头像资料

- 新增 `ProfileModal`：大头像、显示名、@name、类型、runtime、状态、唤醒策略、角色/领域。
- 入口：消息头像、DM 头部头像、Agents 页头像、侧栏自己。
- agent 资料里有「私聊」按钮。

### 5. 历史搜索

- `GET /api/search?q=`：遍历每个房间最近 100 条消息做子串匹配，返回房间/发送者/时间。
- 侧栏搜索框回车进入 `SearchView`；结果显示高亮命中，点击跳回房间并高亮那条消息。
- 受限于最近 100 条；更早需要分页或索引。

### 6. 设置页

- 侧栏「设置」进入 `SettingsView`。
- 系统信息：homeserver、服务器名、human、agent/会话数。
- 每个 agent 可改：显示名、角色、wakePolicy、系统提示。
- `PATCH /api/agents/:id`：更新 store/engine；显示名同步 Matrix profile 和 DM 房间名；系统提示变化会重建 runtime（下一轮生效）。
- 验证：PATCH researcher 的 roles/wakePolicy 成功。

### 7. Web Interface Guidelines 审查

用 `web-design-guidelines` 审了一遍（规则源 raw.githubusercontent 被墙，走 gh-proxy 镜像）。已修：

- `color-scheme` / `theme-color`（深浅色原生控件）。
- skip link + `main` 可聚焦。
- 表单 `name` / `autoComplete` / 用户名 `spellCheck={false}`。
- `touch-action: manipulation`、`overscroll-behavior: contain`、safe-area 底部留白。
- primary/send hover、时间 `tabular-nums`、`Intl.DateTimeFormat`。
- `content-visibility: auto` 给长消息列表；图片有 `info.w/h` 时输出尺寸。
- 模态框统一 `useDialogFocus`：自动聚焦第一个输入、Tab 陷阱、Esc 关闭、关闭后焦点回到触发元素。

剩余：房间导航仍是 button 而非 `<a>`（Cmd/中键不能开新标签）；搜索只覆盖最近 100 条；上传的图片没有 w/h 元数据时仍可能 CLS；设置页离开无未保存提示。

## 补充：真实的"正在思考" + 列表菜单不挡字

- 原来的"正在思考"是前端按发送时间猜的：agent PASS 不产生消息，提示会滞留到 75s 超时，看起来像在干等。
- `bootstrap` 每个房间新增 `activity: { floor, queued, states }`，直接来自 Engine 的 thread.floor：
  - `floor` = 当前真正持有 floor、正在跑 turn 的 agent；
  - `queued` = 在等 floor 的 agent。
- UI 只显示 floor holder「正在思考」、队列「排队中」；floor 释放后自动消失，不再用本地计时器。
- 实测群里发一条：activity 依次 `claude-dev` → `researcher` → 空；提示随 floor 变化。
- 侧栏 `⋯` 改为右侧预留固定列 + 垂直居中，不再覆盖预览文字；右键菜单保留。

## 遗留

- 搜索只覆盖最近 100 条；没有全文索引。
- 设置不能删除/暂停 agent、不能改 runtime、不能移除成员。
- 系统提示改动会重建 runtime，可能打断正在跑的 turn。
- 图片缓存没有清理策略；`app/data/media` 会增长。
- 没有流式输出/工具审批。
