- 记录时间：2026-11-17 下午。
- 目标：长期驻守的第一块核心——任务状态、到期派发、重启不重复。
- 关联：[17 任务台账](../17-task-ledger.md) · [16 长期驻守与 intake](../16-long-running-and-intake.md) · [13 MVP 架构](../13-mvp-architecture.md)

## 实现

- `app/tasks.mjs`：`TaskStore`，持久化到 `app/data/tasks.json`。
- API：
  - `GET /api/tasks`
  - `POST /api/tasks`
  - `PATCH /api/tasks/:id`
  - `POST /api/tasks/:id/checkpoints`
  - `POST /api/tasks/:id/dispatch`
- Scheduler：
  - 启动 5s 后一次、之后每 30s 检查 `pending + dueAt<=now`；
  - 派发前先置 active/写 checkpoint，再以人类身份发消息并 @ owner；
  - 失败置 blocked；owner 暂停直接 blocked；
  - 重启后 active 不重发，pending 到期补发。
- UI：
  - 侧栏「任务」、状态筛选、派发/完成/阻塞/取消/重开/打开房间；
  - 新建任务 modal（标题/描述/owner/房间/到期）。

## 边界

- 重复任务只有固定分钟间隔，没有 cron/工作日/时区规则；停机跨周期不补跑。
- 没有 agent 侧创建/更新任务；没有自动完成检测。
- 没有失败重试/退避；失败即 blocked。
- 没有 turn 级恢复；长任务重启后只能看到 active 状态，不能恢复那一轮。
- 单机内存 tick，没有多实例租约。
