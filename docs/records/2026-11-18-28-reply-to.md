# 2026-11-18-28 消息回复引用

- 记录时间：2026-11-18 凌晨。
- 目标：补 IM 基本能力——对某条消息回复并显示引用。
- 关联：[13 MVP 架构](../13-mvp-architecture.md) · [记录 27 桌面通知](2026-11-17-27-desktop-notifications.md)

## 实现

- 消息悬浮显示「回复」；点击后 composer 显示引用草稿，可 Esc/× 取消。
- 发送时 body 带 `replyTo`；Matrix 使用 `m.relates_to.m.in_reply_to`。
- 服务端 messageView 增加 `replyTo`、`threadId`；消息气泡上方显示“回复 某人：原文预览”。
- 修复 Matrix transport 的主线程 reply 解析：之前只认 `rel_type=m.in_reply_to`，实际 Matrix 是 `m.relates_to["m.in_reply_to"].event_id`；现在能正确读回。
- API：`POST /api/rooms/:id/messages {text, replyTo}`。

## 实测

- script-peer DM 发第一条，拿到 eventId。
- 第二条带 replyTo 发送；返回 message.replyTo 正确。
- 拉取消息：第二条 replyTo 指向第一条，threadId=main，父消息文本正确。
- lint/build 通过；38 tests。

## 边界

- 没有 thread 面板；只做 main thread 的回复引用。
- Agent 回复不会自动带 replyTo（只在 prompt 上下文里看到最近消息）。
- 引用只显示加载到的最近 100 条；更早的父消息显示“更早的消息”。
- 没有 reaction、@ 未读、回复通知。
- 没有消息编辑/删除单条。
