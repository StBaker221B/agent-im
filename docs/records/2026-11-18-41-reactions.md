# 2026-11-18-41 消息 Reaction

- 记录时间：2026-11-18。

## 实现

- MatrixClient：
  - `sendReaction(roomId,eventId,key)` → `m.reaction`，`m.relates_to={rel_type:"m.annotation",event_id,key}`。
  - `#normalize` 识别 `m.reaction`，返回 `kind:"reaction", targetId,key,sender`。
  - Gateway `#ingest` 跳过 reaction，不让它进入 engine/wake。
- Server：
  - `roomMessagesPage` 从消息页里分离 reactions，返回 `{messages,reactions:{targetId:[{key,sender}]},next}`。
  - `POST /api/rooms/:id/reactions {messageId,key}`：校验目标消息，以人类身份发 reaction。
- UI：
  - 消息悬浮 👍 按钮；已点赞后禁用（没有撤销 API）。
  - 气泡下显示 emoji + count chip。

## 验证

- script-peer DM 发一条消息，`POST reactions` 200；
- `GET messages?limit=20` 的 `reactions[eventId]` 返回 `[{key:"👍",sender:"@kudo"}]`。
- lint/build 通过；43 tests。

## 边界

- 只有 👍 快捷按钮；没有 emoji picker/自定义 key（API 支持 key）。
- 不能撤销/切换 reaction（Matrix redact 未做）。
- Agent 没有 reaction 工具；只有人类能点。
- Reaction 事件占分页条数，可能让一页文本消息少于 limit。
- 没有按 reaction 搜索/通知；thread 面板未做。
