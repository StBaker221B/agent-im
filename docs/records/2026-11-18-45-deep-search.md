# 2026-11-18-45 深搜历史

- 记录时间：2026-11-18。
- 目标：C 轨道——搜索不再只看每房间最近 100 条，给一个显式的“深搜”选项。
- 关联：[13 MVP 架构](../13-mvp-architecture.md) · [记录 39 分页](2026-11-18-39-history-pagination.md)

## 实现

- `GET /api/search?q=&pages=N`：`pages` 1–5，每个房间用 Matrix end token 连续翻页，最多 500 条；结果最多 100 条。
- SearchView 增加「深搜历史」checkbox；切换后自动重搜；显示扫描范围。
- 普通搜索仍默认 1 页（100 条），保持速度。

## 验证

- `q=收到&pages=1` 和 `pages=5` 都返回 19 条（当前数据在 500 条内匹配数相同；路由/分页循环正常）。
- lint/build 通过；43 tests。

## 边界

- 不是真正的“搜索结果分页”：一次请求扫完，返回上限 100；没有 offset/cursor。
- 深搜按房间顺序扫，房间多时慢；没有超时/取消。
- 仍只搜 main thread 文本消息；不含 thread 回复、媒体文件名、reaction。
- 结果按时间排序，不按相关度；没有摘要/命中上下文。
